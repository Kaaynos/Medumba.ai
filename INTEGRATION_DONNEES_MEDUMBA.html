3. Syllabaire Medumba

📄 Les syllabes medumba.docx ✓ Intégré

Contenu source

Inventaire phonologique complet de 1147 syllabes Medumba avec leur transcription IPA. Couverture totale de l'alphabet : de a jusqu'à zwi'.

Format des données

// src/data/medumbaSyllables.js export const MEDUMBA_SYLLABLES = [ { syllable: 'a', ipa: '[a]' }, { syllable: 'a\'', ipa: '[ɑʔ]' }, { syllable: 'bə', ipa: '[bœ], [bʉ]' }, { syllable: 'zwi', ipa: '[zɥi]' }, // ... 1143 autres syllabes ];

SyllabeIPANote phonologique

5. Architecture technique des données

Pipeline de traitement

📁Fichiers source (.docx / .xlsx) dans OneDrive
↓Scripts PowerShell + Python → Fichiers .txt intermédiaires
↓generate_data2.mjs → Parse et génère les fichiers JS dans src/data/
↓medumbaExpressions.js importe et fusionne les 3 sources → MEDUMBA_EXPRESSIONS (1218)
↓getExpressionsByLesson(lessonId) → filtre par mots-clés de la leçon
↓buildExpressionQuestions(flashcards) → 3 flashcards + ~10 exercices variés
↓LessonPage → max 13 questions à l'utilisateur (score min 60% pour passer)

6. Ressources non intégrées (bloquées)

🔒 Dictionnaire Medumba 2.pdf — 179 pages. Encodage mojibake total (Latin-1 interprété comme UTF-8). Texte illisible. Nécessite OCR.
🔒 Lexique Médecine.pdf — 118 termes médicaux/neurodéveloppementaux. Même problème d'encodage. Les mots sont fragmentés par des espaces erronés (ex: "gh oÌŒ nmbuâ€™tu" au lieu de "ghǒnmbu'tu"). Nécessite OCR ou re-exportation.
🔒 Dictionnaire Français-Medumba.pdf — ~848 entrées sur 1049 pages. Texte français lisible, diacritiques Medumba partiellement corrompus. Utilisable après normalisation des glyphes.
🔒 Présentation PPTX — Le grenier de la langue Medumba — 89 MB. Contenu culturel avec images et médias. Non extrait. Nécessite LibreOffice ou COM automation.

Ressource disponible non encore intégrée

📚 Dictionnaire des Verbes Medumba — 1384 verbes B–Z avec IPA, classe tonale, transitivité et exemples de phrases. Extrait dans verbes_clean.txt (490 KB). Format riche — chaque entrée contient :

Ba [bá] (1) v.t. Détourner : Bo ba ncua'a. ≈ On a détourné la tontine.

Prévu pour le module Verbes avancé (une fois que la structure de conjugaison est définie dans l'app).
